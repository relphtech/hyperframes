## HyperFrames 是什么

用 HTML、CSS 和可定位的动画来写视频，再渲染成确定的 MP4。
核心理念：写 HTML，就能出视频，而且同一份输入每次渲染结果一致。

- 每个场景就是一份 HTML，时间用 data-* 属性来控制
- 动画可以用常见的 CSS、GSAP、Lottie、Three.js 等方式来写
- 渲染用无头浏览器逐帧抓取，再用 FFmpeg 编码成 MP4
- 不需要构建步骤，HTML 文件本身就能在浏览器里预览

## 环境要求

- Node.js 22 或更新版本
- 已安装 FFmpeg
- 详细用法请看上游文档：hyperframes.heygen.com

## 中文标题模板 zh-hello 用法

示例文件：`examples/zh-hello/index.html`（已于 Day 2 加入本 Fork）。

这个模板只有一屏，适合做视频开场标题：

- 主标题「你好，HyperFrames」：从 0 秒出现，持续 5 秒
- 副标题「用 HTML 写视频的第一支中文模板」：从 0.5 秒出现，持续 4.5 秒
- 标签「Write HTML. Render video.」：从 1 秒出现，持续 4 秒

改法很简单：直接改这三处文字，就能换成你自己的标题、副标题和标签，
不需要改结构和样式。想换时长，改对应元素的 `data-start`（开始时间）
和 `data-duration`（持续时间）即可。

预览：这个 HTML 文件不需要构建步骤，直接用浏览器打开就能看版式；
正式出片时再按上游文档走逐帧渲染流程。

注意事项：

- 动画请用可定位（seekable）的方式写，避免依赖墙钟时间的动画，
  否则逐帧渲染时可能只剩静帧。
- 渲染前提与上面「环境要求」一致：Node.js 22 或更新版本，
  并已安装 FFmpeg；具体渲染步骤请以
  上游文档 hyperframes.heygen.com 为准，本 Fork 不另写未经核实的命令。
