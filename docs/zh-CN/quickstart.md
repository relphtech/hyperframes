# 中文快速开始：从这个 Fork 到第一支视频

本页是 HyperFrames 中文 Fork 的快速开始指南，目标是让第一次用的人
按步骤走下来，就能从一份 HTML 出发，得到第一支视频。
具体渲染步骤请以上游文档（hyperframes.heygen.com）为准，
本 Fork 不另写未经核实的命令。

## 先确认环境

在开始之前，先确认两项渲染前提已经具备：

- Node.js 22 或更新版本
- 已安装 FFmpeg

这两项是本 Fork README-ZH.md 里写明的环境要求，
也是上游逐帧渲染流程的前提。如果还没有，先装好再往下走。

## 第 1 步：拿到这个 Fork

把本仓库（relphtech/hyperframes）取到本地。
本 Fork 保留上游 Apache-2.0 许可证与原作者信息，
自己的改动主要放在中文文档与中文示例里，
这样以后同步上游时冲突更少。

## 第 2 步：先在浏览器里预览一个模板

不需要构建步骤，示例 HTML 本身就能在浏览器里直接打开看版式。
建议先看这一个：

- `examples/zh-hello/index.html`：一屏中文标题模板，
  主标题「你好，HyperFrames」，副标题与标签各一处，
  适合做视频开场标题。

打开后先确认版式、文字与入场节奏是不是你想要的，
再决定改哪里。正式出片时才走逐帧渲染流程，
预览阶段不用先渲染成视频。

## 第 3 步：改成你自己的内容

改模板只需要改文字与时间，不需要改结构和样式：

- 改文字：把主标题、副标题、标签换成你自己的文案。
- 改时长：改对应元素的 `data-start`（开始时间）
  和 `data-duration`（持续时间），就能调整出现与停留时间。
- 改顺序：先想好一屏讲什么、下一屏接什么，
  再按出现时间排好各元素的先后。

同一个思路也适用于另外两个中文模板：

- `examples/zh-product-intro/index.html`：中文产品介绍模板
- `examples/zh-caption/index.html`：中文字幕条模板

先从改一个模板开始，比从空白页写一支视频更快，
也更容易验证渲染流程是否通畅。

## 第 4 步：按上游文档走渲染流程

版式确认无误后，按上游文档 hyperframes.heygen.com 的流程，
把这份 HTML 逐帧渲染成 MP4。注意两点：

- 动画请用可定位（seekable）的方式写，避免依赖墙钟时间的动画，
  否则逐帧渲染时可能只剩静帧。
- 渲染前再核对一次环境要求：Node.js 22 或更新版本，
  并已安装 FFmpeg。

## 第 5 步：检查成片，再改下一版

第一支视频出来后，先看三件事：

1. 文字有没有被裁切或溢出画面
2. 出现与消失的时间点是不是你想要的节奏
3. 画面与文案的意思有没有对上

有问题先回 HTML 里改文字或时间，再重新渲染，
不要同时改版式、文案与时长——一次只改一处，
才知道是哪一步修好了问题。

## 常见卡点

- 预览正常、渲染结果不对：先检查动画是不是可定位的，
  再检查环境要求是否都已满足。
- 不知道下一步改什么：先只改一个模板的一处文字，
  渲染一版确认流程通畅，再扩展到多屏。
- 想加新内容：优先复用已有的中文模板结构，
  而不是每次都从空白页开始。

## 下一步

跑通第一支视频之后，可以继续看本 Fork 的其他中文内容：

- `README-ZH.md`：本 Fork 的说明与路线图，
  以及 zh-hello 模板的详细用法
- `examples/zh-product-intro/index.html`：产品介绍模板
- `examples/zh-caption/index.html`：字幕条模板

本 Fork 会继续往中文友好、开箱即用的方向做，
也欢迎按同样的思路补充新的中文模板与文档。
